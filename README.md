# Data

Place the extracted MHEALTH dataset here as `MHEALTHDATASET/` (containing
`mHealth_subject1.log` through `mHealth_subject10.log` and `README.txt`).

Download from: https://archive.ics.uci.edu/dataset/319/mhealth+dataset

This folder is excluded from version control (see `.gitignore`) — the dataset is not
redistributed in this repository; download it directly from the UCI Machine Learning
Repository using the link above.
